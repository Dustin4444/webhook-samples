# Webhook Samples Documentation

Welcome to the Webhook Samples documentation. This project is a collection of webhook data from different platforms that distribute webhooks.

## What is this project?

This repository contains real-world webhook examples from various platforms, which are used in [Hookdeck console](https://console.hookdeck.com) under "Example Webhooks".

## Getting Started

To get started with the documentation, check out our guide on [Getting started with Vercel Web Analytics](./getting-started-web-analytics.mdx).

## About the Data

Each provider has:
- A directory for each version
- Files for each topic/event type
- Request data including headers and body

The data is packaged into JSON files distributed via HTTP at [samples.hookdeck.com](https://samples.hookdeck.com).
